## Agent skills

### Issue tracker

Issues and specs live as local markdown files under `.scratch/` (gitignored). See `docs/agents/issue-tracker.md`.

### Triage labels

Default five-label vocabulary (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.

### Product specifications

Tracked product specifications live in `docs/specs/`: v0.4 is current and v0.3 is retained for historical reference. See `docs/agents/domain.md`.
